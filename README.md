# FoodApp

A Next.js food application project in my full-stack developer portfolio.

> Status: Development project. Specific features and production readiness have not yet been independently verified.

## Technology

- Next.js 15, React 19 and TypeScript
- Tailwind CSS 4
- MongoDB and Mongoose
- Cloudinary and Multer (media handling dependencies)
- Zod (validation library)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. For production builds run `npm run build` and `npm start`.

Database and media integrations may require environment variables. Do not commit credentials.
